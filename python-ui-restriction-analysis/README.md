# Analysis of Window Flags and UI Persistence in PySide6

## ⚠️ Strict Academic Disclaimer
This repository contains raw proof-of-concept (PoC) code demonstrating how application frameworks interact with native desktop window managers to restrict user interaction. These scripts are provided strictly for behavioral analysis, malware reverse-engineering studies, and defensive UI research. 

**WARNING:** The scripts in this repository intentionally override default operating system close events (`Alt+F4`, window controls) and force focus retention. They do not contain a built-in UI escape mechanism. Run them only within an isolated virtual machine (VM) or test environment. 

The author assumes no responsibility for system instability, data loss, or misuse of this research material.

---

## Technical Behavior Analysis

This research project isolates two specific mechanisms used by restrictive software (such as aggressive adware or system lockers) to control user real estate:

### 1. Window Flag Manipulation (`Qt.FramelessWindowHint` & `Qt.WindowStaysOnTopHint`)
By combining these native Qt flags, the application strips the operating system's window decorations (title bars, minimize/maximize buttons, and close boxes) while forcing the window rendering layer to sit above all other active processes.

### 2. Event Interception (`closeEvent` & `changeEvent`)
* **`closeEvent(self, event)`**: The scripts invoke `event.ignore()`, which explicitly drops the OS signal generated by standard termination shortcuts like `Alt+F4`.
* **`changeEvent(self, event)`**: The code monitors for `WindowStateChange` signals. If the window manager attempts to minimize the window or shift focus, the script programmatically resets the state to `Qt.WindowNoState`, triggers `.show()`, and calls `.raise_()` to forcibly snap back into the foreground.

## Safe Analysis Instructions
To inspect or trace the execution of these handlers safely:
1. Ensure your Python environment is inside a secure lab environment or VM.
2. Install dependencies: `pip install PySide6`
3. If you run the scripts and need to terminate the process without restarting your machine, use an external terminal or SSH session to kill the Python process:
   ```bash
   # On Windows (via separate CMD/PowerShell)
   taskkill /F /IM python.exe
   
   # On macOS/Linux (via Terminal)
   pkill -f python3
   ```
